# Perklo — live UK deals, global voucher codes and price history over MCP

[![Listed in Awesome MCP Servers](https://sagargupta.online/awesome-mcp-servers/badge.svg)](https://github.com/Sagargupta16/awesome-mcp-servers)

Hi, I'm Tian. I'm building **Perklo**, an MCP server (Model Context Protocol) that gives AI shopping agents live UK deals, global voucher codes, ticket announcements and price history — with 30 tools and no API key.

## What's new

- **price_history** — check how a product's price has changed over time.
- **find_best_deal** — find the best current deal for something you're looking for.
- **cheapest_now** — see the cheapest price available right now.

## Try it

- MCP server endpoint: `https://www.perklo.lol/mcp`
- Source code: [github.com/tianrich/perklo-mcp](https://github.com/tianrich/perklo-mcp)
- Developer docs: [perklo.lol/developers](https://www.perklo.lol/developers)

Whether you're building a shopping agent, hunting Black Friday bargains or tracking prices, Perklo plugs straight into your MCP client.
